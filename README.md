# Clinic Flow - クリニック向け 出勤・ポイント管理システム

クリニック等のスタッフ用のシンプルな出勤・打刻アプリ、および管理者用の勤怠・ポイント管理ダッシュボードを一体化したシングルページアプリケーション（SPA）です。

## 🌟 主な特徴

1. **シンプルなスタッフ打刻画面**
   - スタッフを選択して「出勤」「退勤」「休憩」を押すだけのシンプルな操作。
   - 「休憩」ボタンは現在の状態に応じて動的に「休憩開始」「休憩終了」と変化します。
   - 誰が休憩中であるかが画面上部にリアルタイムで明示されます（パルスアニメーション付き）。

2. **管理者向けダッシュボード（パスワード保護）**
   - **打刻履歴の管理**: 日毎の打刻ログ、実労働時間をテーブル形式で確認可能。
   - **残業理由の入力・タイムカード不正防止**:
     - 所定時間を超える勤務（実働8時間超、または18:30以降の退勤）時に、退勤ポップアップで残業理由の選択・入力を必須化。
     - 打刻履歴テーブルおよびCSVエクスポートにも残業理由が明記されます。
   - **打刻ミス・漏れの修正申請＆承認ワークフロー**:
     - スタッフ画面から「打刻修正・ミスの申請」を直接送信可能（手書きメモや口頭連絡が不要）。
     - 管理画面の「申請管理」タブで未承認件数が赤バッジ表示され、ワンクリックで承認／却下。
     - 承認すると打刻履歴・Excel出力用データに即時反映。過去の承認履歴もすべて保存。
   - **時間集計表（Excel）ワンクリック自動出力**:
     - クリニック専用の給与計算用エクセルシート（`時間集計表.xlsx`）をワンクリックで自動生成・ダウンロード。
     - 1枚目（セットシート）の期間（〇年〇月16日〜翌月15日）を自動設定。
     - スタッフごとのシート（木村、植西、末廣等）へ、午前診（13時前: O・P列）／午後診（13時以降: U・V列）を自動判定して打刻（1000等の4桁形式）を転記。
     - 新シート「感謝ポイント一覧」を自動作成し、スタッフ別の獲得・贈呈状況サマリーや感謝メッセージ履歴を綺麗に集計。
   - **CSVエクスポート**: エクセル等で即座に開くことができるBOM付きUTF-8形式でのCSV出力。
   - **スタッフ管理**: 新しいスタッフの追加、不要になったスタッフの削除。
    - **360度評価ポイント（ピアボーナス）**:
      - 3時間以上の勤務で2ポイント、6時間以上の勤務で3ポイントが退勤時に付与されます。
      - 獲得したポイントは退勤時に、感謝や評価を添えて他のスタッフに贈る（プレゼントする）ことができます。
      - 誰が誰に何ポイント贈ったかも、打刻履歴やCSVエクスポートにすべて記録されます。

3. **プレミアムでクリーンなUIデザイン**
   - クリニックらしい清潔感のあるブルー・ミントカラーをベースとした配色。
   - 透過ガラス風の背景（ガラスモフィズム）と美しいグラデーション。
   - ホバーエフェクトやスライドトースト等のインタラクションアニメーション。

## 🚀 起動方法

本システムはサーバーの構築やインストール作業なしで、ブラウザのみで動作します。

1. 本フォルダにある `index.html` をブラウザ（Google Chrome、Microsoft Edge、Safari 等）で開きます。
   - ※ファイルをダブルクリックするだけで起動します。

## 💾 データの保存と複数PC同期について

本アプリケーションは基本、各端末のブラウザ内（`localStorage`）に高速保存されますが、**Googleスプレッドシート連携（プランB）** を設定することで、複数PC・タブレット間での完全自動同期とリアルタイムバックアップが可能になります。

### 🌐 複数PC同期の設定手順（Googleスプレッドシート連携）

院長先生や管理者の**個人Googleアカウント**で設定するため、スタッフに打刻履歴を見られる心配がありません。

1. 個人のGoogleドライブ（[drive.google.com](https://drive.google.com/)）で、新規スプレッドシートを作成します（シート名例: `Clinic Flow 勤怠データベース`）。
2. メニューの **「拡張機能」>「Apps Script」** を開きます。
3. もともと入っているコードを消去し、本フォルダ内の [google-apps-script.js](file:///c:/Users/awaza/product/出勤アプリ/google-apps-script.js) の内容をすべて貼り付けます。
4. 右上の **「デプロイ」>「新しいデプロイ」** を選択：
   - 種類: **「ウェブアプリ」**
   - 次のユーザーとして実行: **「自分」**
   - アクセスできるユーザー: **「全員」**
5. **「デプロイ」** を押し、画面の指示に従ってアクセスを承認します。
6. 発行された **「ウェブアプリ URL」**（`https://script.google.com/macros/s/.../exec`）をコピーします。
7. 出勤アプリの管理画面 > 「360度評価ポイント」タブにある **「GAS ウェブアプリ URL」** に貼り付けて **「URLを保存」** をクリックします。

※URLを設定すると、画面上部に「☁️ クラウド同期済」が表示され、出勤・退勤・申請・承認のすべてが自動でリアルタイム同期されます。別のパソコンでも同じフォルダの `index.html` を開いて同じURLを設定すれば、どのPCからでも全く同じ最新データが共有されます。
